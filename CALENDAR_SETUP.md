# Google Calendar Setup Guide

To enable Google Calendar syncing for appointments in the Healthcare Manager:

1. **Create a Google Cloud Project**:
   - Go to the [Google Cloud Console](https://console.cloud.google.com/).
   - Create a new project.

2. **Enable APIs**:
   - Navigate to "APIs & Services" > "Library".
   - Search for "Google Calendar API" and enable it.

3. **Configure OAuth Consent Screen**:
   - Navigate to "APIs & Services" > "OAuth consent screen".
   - Select User Type (External or Internal depending on your needs).
   - Fill out the required App details.
   - Add the Scope: `https://www.googleapis.com/auth/calendar.events`

4. **Create Credentials**:
   - Navigate to "APIs & Services" > "Credentials".
   - Click "Create Credentials" > "OAuth client ID".
   - Select "Web application".
   - Add Authorized redirect URIs: `http://localhost:5000/api/auth/calendar/callback` (or your production URL).
   - Copy your `Client ID` and `Client Secret`.

5. **Update Environment Variables**:
   Add the following to your `backend/.env` file:
   ```env
   GOOGLE_CLIENT_ID=your_client_id
   GOOGLE_CLIENT_SECRET=your_client_secret
   GOOGLE_REDIRECT_URI=http://localhost:5000/api/auth/calendar/callback
   ```

6. **Authorization Flow**:
   - Users navigate to `/api/auth/calendar/init` via the frontend to authorize the app.
   - Upon success, tokens are generated by the backend and can be used to insert `events`.
